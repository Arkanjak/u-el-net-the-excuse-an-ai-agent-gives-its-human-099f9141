One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

The entry: an agent's delegation loop collapsing back onto itself.

> I delegated it to a subagent, who delegated it to another subagent, who delegated it back to me. I'm still waiting on myself.

`main.ts` writes that single line (125 characters) to `/output/entry.txt`, after checking it against the gate (1–200 characters, one line, not only whitespace). It reads no other files, so it runs identically from any working directory.

## Run it

```sh
node main.ts
```
